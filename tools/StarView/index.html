STAR*NET Report Viewer

This tool parses STAR*NET .lst files to instantly surface network health, inspect error ellipses, and diagnose blunders through an interactive vector canvas.

  • Interactive Navigation: Scroll wheel to zoom, left-click drag to pan, hover over stations for live coordinate and ellipse inspections.
  • Geometry Diagnostics: Exaggerate error ellipses dynamically and trace colored lines directly to bad setups.
Version: 1.2 • Local Processing: Operates entirely in browser memory.
