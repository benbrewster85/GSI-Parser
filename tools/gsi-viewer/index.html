GSI Viewer

ℹ️ About GSI Viewer

Features

  • View Leica GSI format data with intelligent format detection.
  • Automatically detect data type (level, TPS) and separate calibration tests.
  • Aggregate readings for cleaner analysis.
  • Export to multiple formats: Reports, StarNet, CSV.

Supported Formats

  • .gsi - Standard GSI format files
  • .txt - Text-based GSI data

How to Use

  1. Upload your GSI file using drag & drop or file selection.
  2. Review the parsed data in the preview table.
  3. Remove calibration data and erroneous lines if needed, using the interactive record editor.
  4. Configure advanced options if needed.
  5. Set known benchmark if required.
  6. Export your data in the desired format.

Technical Notes

This viewer is optimised for Leica GSI data and supports both GSI-8 and GSI-16 formats. Currently only parsing sets-of-angle (TPS) and Level type data, processing of GNSS and other forms of GSI and survey data are in development.
