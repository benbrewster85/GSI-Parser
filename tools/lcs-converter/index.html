LCS Conversion Utility

This tool computes 3D spatial transformations between cartesian coordinates (LSG2025) and the standard Linear Code System (LCS) used by Tranport for London for referencing locations and assets on the network. Details of the LCS system can be found in the TfL Standard S1035

Processing Modes

  • Coordinates → LCS: Upload point files containing absolute map coordinates. The tool outputs corresponding LCS values. Input coordinates must be in London Survey Grid (2025) - if your input is in BNG/OSGB we have a tool for that here

  • LCS → Coordinates: Supply standard asset location text strings to reconstruct absolute 3D track positions based on design baseline data profiles (In London Survey grid).

Centerline Projection Feature

When running coordinate conversions, the tool automatically calculates the true position of the point projected directly back onto the track centreline (E, N, Z)


LCS Builder Feature

The LCS Builder allows users to manually create LCS entries for conversion to LSG coordinates. Beware the lack of a save function if building multiple entries.

Note: This tool is currently in beta and may contain bugs or limitations. Always check results before using them in production.


Centreline information used herein is node-based and does not represent the true geometry of the track.
