Linear Coordinate Suite (LCS)

This utility computes 3D spatial transformations between engineering coordinates and the standard Linear Code System (LCS) infrastructure matrix natively within the web client engine.

Processing Modes

  • Coordinates → LCS: Upload point files containing absolute map coordinates. The tool outputs corresponding LCS values. Input coordingates must be in London Survey Grid (2025) - if your input is in BNG/OSGB we have a tool for that here
  • LCS → Coordinates: Supply standard asset location text strings to reconstruct absolute 3D track positions based on design baseline data profiles (In London Survey grid).

Centerline Projection Feature

When running coordinate conversions, the tool automatically calculates the true position parameters of the point projected orthogonally directly back down onto the line axis center datum profile ($E, N, Z$), simplifying track clearance measurements.

Version: 2.0 (Client Matrix Sandbox) • Method: 3D Parametric Vector Projection
