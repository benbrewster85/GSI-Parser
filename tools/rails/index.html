Rail Analysis Dashboard

ℹ️ About The Rail Dashboard

Features

  • Processes CSV files of surveyed rail points (E, N, H).
  • Calculates centreline, radius, cant, and 2m twist.
  • Advanced settings allow for customisation of results.
  • Fully interactive charts and data table.

How to Use

  1. Upload your CSV file (With headers ID, E, N, H).
  2. Point order is not important - this will be calculated
  3. Analyse the data in the table and charts.
  4. Use Advanced Settings to re-define the start of the track if needed.
